# 📖 Gestor de libros 📖

Este gestor de libros es una pequeña aplicación hecha con Java, SQL y JavaFX.

<br>

<img src="RegistroLecturas.PNG">

<br>

📚 **Añade libros con sus características (título, autor, género...)**

👥 **Añade autores junto con una breve descripción**

💬 **Clasifica libros por su estado (PENDIENTE, LEIDO, LEYENDO o ABANDONADO)**

📍 **Lleva un seguimiento de lectura dependiendo de la página por la que vas leyendo y la fecha de comienzo y fin de la lectura**

⭐ **Puntua libros con estrellas de 0-5**

💗 **Añade libros y autores a favoritos**

📝 **Añade citas o notas**

📊 **Ve tus estadísticas según tu total de libros, tus libros/autores favoritos...**

<br>

**DESCARGA LA APP INSTALABLE V1.0 EN RELEASE**

En caso de descargar el archivo zip, ejecutar la aplicación con:

``mvn javafx:run``

<br>

**RECOMENDACIÓN:** Añadir las url de portada desde ***Open Library***
